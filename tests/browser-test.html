🔍 Proctor Extension — Browser Feature Tests

Test page — Load extension, mở trang này, click Run All Tests

Hướng dẫn:
1. Load extension trong chrome://extensions → Load unpacked
2. Mở popup, nhập thông tin phòng thi → Start Proctoring
3. Mở trang này trong tab đang được giám sát
4. Click Run All Tests — Các test tự động sẽ chạy
5. Một số test yêu cầu thao tác tay (có ghi chú)
